# Temirlan Animation Studio — план и роли

Цель: 2D-киностудия для мультфильмов, которая работает в браузере Android-телефона и ставится на
главный экран как приложение (PWA). Технологии: HTML, CSS и JavaScript без сборки и без внешних
библиотек.

## Роли и за что они отвечают

| Роль | Зона ответственности | Файлы |
| --- | --- | --- |
| Менеджер проекта | План, порядок работ, структура проекта, этот документ | `docs/PLAN.md`, `README.md` |
| Дизайнер персонажей | Мультяшные персонажи, их цвета и эмоции | `js/render/characters.js`, `js/core/objects.js` |
| Разработчик анимации | Кадры, воспроизведение, плавное движение (промежуточные кадры), звук, экспорт видео | `js/core/tween.js`, `js/core/player.js`, `js/ui/timeline.js`, `js/ui/tween-sheet.js`, `js/ui/sound-sheet.js`, `js/services/audio.js`, `js/services/azure-tts.js`, `js/services/video-export.js` |
| Дизайнер фонов | Готовые сцены и окружение | `js/render/scenes.js` |
| Тестировщик | Юнит-тесты, сквозные тесты в браузере, проверка вёрстки на телефоне | `tests/` |

Общие части (холст, панели, хранение) поддерживают все роли вместе: `js/ui/`, `js/services/`.

## Структура проекта

```
web/
  index.html              разметка приложения
  manifest.webmanifest    данные для установки на телефон
  sw.js                   офлайн-режим (меняйте VERSION при каждом обновлении)
  css/styles.css          стили, сначала мобильная вёрстка
  icons/                  иконки приложения
  js/
    main.js               точка входа, связывает компоненты
    core/                 данные: проект, объекты, история отмены, плеер, переходы, пример
    render/               рисование: кадры, фигуры, персонажи, фоны
    ui/                   компоненты интерфейса: холст, панели, таймлайн, меню
    services/             хранение в браузере и экспорт видео
  tests/                  юнит-тесты и сквозной тест
  docs/PLAN.md            этот план
```

## Этапы

1. **Версия 1 (готово).** Холст с рисованием пальцем, фигуры и персонажи, перемещение, поворот и
   масштаб, таймлайн, слои, воспроизведение, сохранение и открытие, экспорт видео.
2. **Киностудия (готово).** Работа по ролям; 8 персонажей; 6 готовых фонов; плавное движение между
   кадрами с выбором характера движения; пример анимации при первом запуске; новые тесты.
3. **Звук (готово).** Музыка и звуки из файла, запись голоса с микрофона, голоса персонажей из
   текста через Azure AI Speech (казахские, русские и английские голоса, мультяшные характеры),
   звук при воспроизведении и в экспортированном видео.
4. **Дальше (предложение).**
   - Камера: наезд, отъезд и панорама по сцене.
   - Позы персонажей: руки, ноги и голова двигаются отдельно.
   - Текст и титры.
   - Несколько сцен в одном фильме.

## Как проверяем каждое изменение

1. `node --test web/tests/model.test.mjs`: модель проекта, геометрия и переходы.
2. `node web/tests/e2e.cjs http://localhost:8765/`: все кнопки в Chromium с эмуляцией Pixel 7,
   включая экспорт видео; тест падает при любой ошибке в консоли.
3. Скриншоты в вертикальной и горизонтальной ориентации телефона и на компьютере.
4. Перед публикацией: увеличить `VERSION` в `sw.js`.

## Голоса Azure: как подключить

1. Создайте бесплатный аккаунт на https://azure.microsoft.com/free.
2. В https://portal.azure.com создайте ресурс **Speech** (тариф Free F0, регион например West Europe).
3. В ресурсе откройте «Ключи и конечная точка», скопируйте Ключ 1 и регион.
4. В студии: таймлайн → кнопка «Звук» → «Настройки Azure», вставьте ключ и регион.

Ключ хранится только в браузере телефона (localStorage) и не попадает в файл проекта и в репозиторий.
